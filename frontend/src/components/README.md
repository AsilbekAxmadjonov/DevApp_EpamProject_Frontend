# Components Directory

## Purpose
Houses all reusable and shared UI components used across the application.

## Components

- **Loader.jsx** – A loading spinner displayed during async operations.
- **Navbar.jsx** – The navigation bar containing links to different app pages.
- **PostCard.jsx** – A card component that displays individual posts with actions like like, comment, and bookmark.

## Notes
Each component is modular and styled based on the Figma design: [Figma Link](https://www.figma.com/design/wbYCktw4D2wjAm5lJUYjxg/WP-Final-Project).

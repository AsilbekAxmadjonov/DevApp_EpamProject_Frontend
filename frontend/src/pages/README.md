# Pages Directory

## Purpose
Contains all top-level views rendered by routes in the application.

## Pages

- **BookmarksPage.jsx** – Displays all bookmarked posts of the current user.
- **CreatePage.jsx** – UI for creating a new post.
- **HomePage.jsx** – Displays feed with all posts.
- **LoginPage.jsx** – Login form.
- **RegisterPage.jsx** – Registration form.
- **ProfilePage.jsx** – User’s profile with posts and info.
- **NotFoundPage.jsx** – 404 fallback page.

## Notes
All pages follow the UI design from Figma and are connected via `AppRouter.jsx`.

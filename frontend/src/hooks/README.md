# Hooks Directory

## Purpose
Custom React hooks used for reusability and encapsulating logic.

## Hooks

- **useAuth.js** – Hook to access and manage authentication state from `AuthContext`.
- **useFetch.js** – Wrapper around `fetch()` for standardized API communication with loading and error handling.

## Notes
These hooks help separate logic from UI components, making the app cleaner and more maintainable.
